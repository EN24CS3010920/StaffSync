# StaffSync

A React + Vite HR workspace dashboard demo.

## Run locally

1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in the terminal.

## Deploy on Vercel

Use the repository root (`./`) as the Root Directory, select Vite if detected, set Build Command to `npm run build`, and Output Directory to `dist`.

This version is a frontend demo using sample data; it is not connected to the Express/MongoDB backend.
